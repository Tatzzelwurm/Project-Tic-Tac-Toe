# Project-Tic-Tac-Toe
This is a [Tic-Tac-Toe game project](https://tatzzelwurm.github.io/Project-Tic-Tac-Toe). You can play it both in the browser (via the UI) and in the developer console!

## Console Commands
- **Make a move:** `gameController.makeMove(index)` — index 0 to 8
- **Rename player:** `gameController.setPlayersNames("new name", index)` — index 0 (X) or 1 (O)
- **Update UI after rename:** `screenController.updatePlayerNames()`
- **Restart game:** `gameController.restartGame()`
